# Screenshot shot list

The public App Store images are in `public-2560x1600/`. They are captured in light mode at **2560 × 1600 px**, a supported Mac screenshot size in App Store Connect. Do not upload the existing `docs/image.png` because it is not 16:10.

Use realistic sample data without personal calendar names or events.

1. `01-board-and-details.png` — populated Today, This Week, and Backlog lanes with a selected task, checklist, and Markdown note.
2. `02-calendar-planner.png` — Calendar Planner with its task shelf and calendar connection flow.
3. `03-week-view.png` — board and Week View shown together.
4. `04-folder-sync.png` — Data settings with local Markdown archive, backup, and folder-sync actions.

`iap-review-pro-lifetime.png` is the separate screenshot already used for IAP review metadata. Do not include it in the public screenshot upload.

Screenshots must show the app in use. Keep overlays short and ensure the first screenshot communicates the Today / This Week / Backlog workflow without requiring its caption.
