# Screenshot shot list

Capture every image at **2560 × 1600 px**. App Store Connect requires one to ten Mac screenshots at a supported 16:10 size; do not upload the existing `docs/image.png` because it is not 16:10.

Use realistic sample data without personal calendar names or events.

1. **Plan today without losing the week**
   - Board view with populated Today, This Week, and Backlog lanes.
2. **Every task can hold a real note**
   - Selected task with subtasks and formatted Markdown visible.
3. **Turn tasks into time blocks — Pro**
   - Calendar Planner with a task shelf and week calendar.
4. **Your files, in your folder — Pro**
   - Data settings showing a selected sync folder and healthy status. Redact the home-folder username.
5. **One purchase. No subscription.**
   - today-md Pro settings screen showing the localized $19.99 lifetime price from StoreKit testing.

Screenshots must show the app in use. Keep overlays short and ensure the first screenshot communicates the Today / This Week / Backlog workflow without requiring its caption.
